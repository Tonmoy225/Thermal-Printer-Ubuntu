# PrintHub

Next.js 16 + Tailwind 4 + Better Auth + MongoDB. Web Bluetooth diye MX10 thermal printer e print.

## Setup
1. `npm install`
2. `.env.local.example` copy kore `.env.local` banao, value gulo bosao
3. `npm run dev` then http://localhost:3000

## Admin
`.env.local` er ADMIN_EMAIL diye Sign up korle oi account admin hobe. Tarpor /admin e jao.

## Deploy (Vercel)
Vercel Environment Variables e MONGODB_URI, BETTER_AUTH_SECRET, BETTER_AUTH_URL (deploy link), ADMIN_EMAIL dao.
